Connect DaVinci Resolve

To pull captions from your timeline, you'll need:

  1. Resolve is running with a project open.
  2. External scripting is enabled — in Resolve, go to Preferences → General → External scripting using and set it to Local.
  3. A timeline is active with a subtitle track that contains items.

Once that's set up, this app reconnects automatically — usually within a few seconds.
